## 2. 这是什么

针对一套 127㎡ 毛坯房（雍贤山庐 7-1004）的装修预算总表，做成一个交互式网页：

- **4 个资金 KPI + 完成进度**：总预算 / 已付款 / 待安排资金 / 特别省下，带数字增量动画
- **按施工阶段分组的可编辑表格**（编号 01 房屋交付前 → 12 结算备用金，实际阶段 + "回款"与"特别省下的钱"特殊节点）
- **点击任意单元格即可编辑**，改动同步保存，KPI 与阶段汇总实时联动
- **2 个 Canvas 自绘图表**：各阶段预算 vs 已付款（横向条形图）、整体资金构成（环形图）
- **搜索 / 状态筛选 / 阶段折叠 / 二级时间线 / 回到顶部 / 回到流程开始**
- **完整移动端响应式适配** + anime.js 动效

## 3. 数据模型（核心）

页面数据是一个"阶段数组"，每个阶段含若干"条目"。这是理解整个项目的关键结构：

```js
// SEED：二维结构 —— 阶段(stage) → 条目(item)
[
  {
    "stage": "04 防水与瓦工瓷砖",   // 阶段名（编号+名称）
    "noStat": false,                // 可选：true=不计入统计（仅"回款"节点用）
    "items": [
      {
        "cat": "瓷砖",              // 类别
        "space": "全屋",           // 空间
        "name": "瓷砖尾款",         // 项目名称
        "brand": "",               // 品牌/规格
        "budget": 15000,           // 预算款
        "paid": 12150,             // 已付款
        "date": "2026-07-08",      // 日期
        "status": "已完成",         // 已完成 / 未完成
        "note": "已付 ¥6,480 + ¥5,670 = ¥12,150"  // 备注
      }
    ]
  }
]
```

**统计口径**：所有 KPI 与图表只统计 `noStat !== true` 的普通阶段。"回款 · 回收返款"节点单独展示、不计入总预算/已付等；"特别省下的钱"节点只计入省下金额。

**当前数据快照**（截至 2026-07-08，v7）：11 个统计阶段 + 1 回款节点 + 1 省钱节点，74 个计入统计的条目，**总预算 ¥217,820**，**已付款 ¥96,604**，回款（不计入统计）合计 ¥2,530。

## 4. 给接手 AI 的重要提示

1. **单文件架构**：`src/index.html` 是唯一的可运行产物。HTML/CSS/JS/anime.js/SEED 数据全部内联在这一个文件里。修改就直接改它。
2. **localStorage 版本键**：代码里有 `const LS_KEY = "yxsl_budget_v7"`。页面加载时**优先读 localStorage，其次用 SEED**。⚠️ **只要你改了 SEED 初始数据，就必须同步递增这个 key**（如 v7→v8），否则用户浏览器里的旧缓存会覆盖你的新数据，导致"改了看不到"。这是本项目最容易踩的坑。
3. **数据同步靠导入/导出**：页面数据存在用户浏览器本地，开发者/AI 无法直接读取用户的手动修改。页面已内置「导出数据」「导入数据」按钮（JSON），跨版本迁移数据请走这个通道。
4. **图表是纯 Canvas 手绘**，非图表库，改图表要改 `drawBar` / `drawDonut` 函数。
5. **详细信息见 docs/**：需求由来看 `01`，代码结构看 `02`，视觉规范看 `03`。
