# 架构与实现说明

面向接手的 AI / 开发者，说明 `src/index.html` 的**代码结构、数据模型、关键函数、可扩展点**。全部代码在这一个文件里，无构建步骤。

---

## 1. 文件整体结构

`src/index.html` 自上而下分为四段：

| 区段 | 行号范围（约） | 内容 |
|---|---|---|
| `<style>` | 8–220 | 全部 CSS（CSS 变量、KPI、工具条、阶段块、表格、图表、toast、悬浮按钮、响应式） |
| `<body>` 静态骨架 | 222–270 | header、KPI 容器、进度条、图表卡片、工具条、`#stages` 容器、footer、两个悬浮按钮、toast |
| `<script>` #1 | 272–281 | 内联的 **anime.js v3.2.2**（压缩源码，MIT，离线） |
| `<script>` #2 | 282–658 | 应用逻辑：SEED 数据 + 所有函数 + 事件绑定 + 初始化 |

页面**没有任何外链**（无 CDN、无字体文件、无后端），双击即用。

## 2. 数据模型

### 2.1 SEED（初始数据，行 ~284）
二维结构：**阶段数组** → 每个阶段的 **条目数组**。

```js
const SEED = [
  { "stage": "01 房屋交付前", "items": [ { …item… }, … ] },
  …
  { "stage": "回款 · 回收返款", "noStat": true, "items": [ … ] }  // 特殊节点
];
```

**阶段对象字段**：
- `stage` — 阶段名，格式「编号 + 名称」（如 `04 防水与瓦工瓷砖`）；图表里用 `replace(/^\d+\s*/,'')` 去掉编号。
- `items` — 条目数组，可为空（如「12 结算与备用金」当前为空）。
- `noStat`（可选）— `true` 表示**不计入任何统计**，仅「回款 · 回收返款」节点使用。

**条目对象字段**（10 个）：
| 字段 | 含义 | 类型 |
|---|---|---|
| `cat` | 类别 | string |
| `space` | 空间 | string |
| `name` | 项目名称 | string |
| `brand` | 品牌/规格 | string |
| `budget` | 预算款 | number |
| `paid` | 已付款 | number |
| `saved` | 省下金额，仅省钱节点使用 | number |
| `date` | 日期 | string(YYYY-MM-DD) |
| `status` | 状态 | `"已完成"` / `"未完成"` |
| `note` | 备注 | string |

> `data/budget-seed.json` 是从 SEED 抽出的独立副本，内容与页面内 SEED 一致，便于程序化读取。**两者需保持同步**。

### 2.2 运行时数据 DATA 与持久化
```js
const LS_KEY = "yxsl_budget_v7";
function loadData(){ 优先 localStorage[LS_KEY]，否则深拷贝 SEED }
function saveData(){ localStorage[LS_KEY] = JSON.stringify(DATA) }
let DATA = loadData();
```
- **加载优先级**：localStorage 缓存 > SEED。
- ⚠️ **改 SEED 必须递增 `LS_KEY`**（如 v6→v7），否则旧缓存覆盖新数据。这是本项目最高频的坑（详见 README 第 4 节）。

## 3. 关键函数速查

### 统计层
| 函数 | 作用 | 备注 |
|---|---|---|
| `calcKPI()` | 遍历 DATA 累加得 `{budget,paid,saved,remain,done,todo}` | `remain = budget - paid`，省钱节点只计入 `saved` |
| `stageSum(s)` | 单个阶段的 `{b,p,saved}` 小计 | 用于阶段头汇总 |
| `stageData()` | 过滤出「有条目且非 noStat 且金额>0」的阶段，供图表用 | 去掉阶段编号前缀 |

### 渲染层
| 函数 | 作用 |
|---|---|
| `buildKPI()` | 依据 `KPI_DEFS` 首次生成 6 张 KPI 卡片 DOM（只建一次） |
| `renderKPI()` | 计算 KPI → 数字增量动画 → 更新进度条/节点数 → 触发 `drawCharts()` |
| `animateNumber(el,to,money)` | requestAnimationFrame 缓动计数（ease-out-cubic，700ms） |
| `renderStages()` | 依据 `filter`/`keyword` 渲染所有阶段表格；回款节点用 `REBATE_COLS`，普通节点用 `COLS`；末尾调用 `bindEditing()` + `observeStages()` |
| `refreshStageSum(si)` | 编辑后仅刷新单个阶段头的汇总（避免整表重渲染） |

### 编辑与交互层
| 函数 / 逻辑 | 作用 |
|---|---|
| `bindEditing()` | 给 `.cell` 绑定 blur 保存（金额清洗 `,¥空格`）、Enter 失焦；给 `.status-badge` 绑定点击切换已完成/未完成 + anime 弹跳 |
| `observeStages()` | IntersectionObserver 让阶段进入视口时加 `.in`；配合 anime.js `stagger` 做阶段头 + 行的交错进场；并绑定阶段头点击折叠 |
| 工具条事件 | 搜索输入、筛选 chip、展开/收起全部、恢复初始数据 |
| 导出 / 导入 | `exportBtn` 下载 `DATA` 为 JSON；`importFile` 读取 JSON、校验含 `items` 后覆盖 DATA |
| 悬浮按钮 | `#top` 回到顶部、`#toStart` 平滑滚动到第一个阶段（带 anime 弹性反馈） |

### 图表层（纯 Canvas 手绘，非图表库）
| 函数 | 作用 |
|---|---|
| `setupCanvas(cv,cssH)` | 处理 devicePixelRatio 高清适配，返回 `{ctx,w,h}` |
| `drawCharts()` | 用 rAF 播放 900ms 进场动画，逐帧调用下面两个 |
| `drawBar(prog)` | **横向条形图**：各阶段「预算款(金) vs 已付款(绿)」双色双条，`prog`>0.9 时标注金额 |
| `drawDonut(prog)` | **环形图**：已付款 vs 待安排资金，中心显示「已付占预算 %」，图例注入 `#donutLegend` |
| `roundRect(...)` | 圆角矩形工具 |

> ⚠️ 命名提醒：条形图函数是 **`drawBar`**（不是 `drawBarChart`）。改图表就改 `drawBar` / `drawDonut`。

### 初始化（文件末尾）
```js
renderKPI(); renderStages();          // 首屏渲染
if(window.anime){ … }                 // KPI 卡片弹入 + header 标题进场
```

## 4. 一次编辑的数据流（示例）

用户改某个单元格金额：
```
单元格 blur
 → 清洗金额字符串（去 , ¥ 空格）
 → 写回 DATA[si].items[ii][k]
 → saveData()  // 存 localStorage
 → renderKPI() // 重算 KPI + 重绘图表
 → refreshStageSum(si) // 刷新该阶段汇总
 → toast('已保存 ✓')
```
状态徽章点击同理：切换 `status` → 保存 → 重算 KPI → anime 弹跳反馈。

## 5. 可扩展点（给接手 AI）

- **加字段/列**：在 `COLS`（普通节点）或 `REBATE_COLS`（回款节点）里加列定义，SEED 每个 item 补对应字段即可。金额列在 `cls` 里带 `money` 会自动右对齐 + 格式化 + 参与编辑清洗。
- **加阶段**：往 SEED 加一个 `{stage, items:[…]}`。若不想计入统计，加 `noStat:true`。
- **改统计口径**：改 `calcKPI()`；KPI 卡片增减改 `KPI_DEFS`。
- **换图表样式**：改 `drawBar` / `drawDonut`；换成图表库需自行引入（当前刻意零依赖）。
- **升级数据**：改 SEED 后**务必**递增 `LS_KEY`，并同步更新 `data/budget-seed.json`。
- **跨设备迁移用户数据**：走页面的「导出/导入 JSON」，不要试图直接读用户的 localStorage（读不到）。
